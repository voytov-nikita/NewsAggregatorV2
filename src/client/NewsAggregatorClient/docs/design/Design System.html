Design System

Единый источник правды для NewsAggregator: токены, типографика, компоненты и состояния. Используется как референс при разработке прототипа и реального приложения.

01 Colors

Тёмная тема — основная. Светлая поддерживается полностью. Все цвета выражены как CSS custom properties и переключаются на корне через [data-theme].

02 Category palette

Каждая категория контента имеет свой hue в OKLCH — это даёт визуальный код, который ведёт пользователя по ленте, и при этом сохраняет одинаковый contrast/chroma.

Technology · 220 Architecture · 160 Backend · 30 Frontend · 280 Database · 200 DevOps · 120 Real-time · 10 State · 250

Формула: oklch(55% 0.14 H / 0.12) для фона, oklch(68% 0.14 H) для текста и точки. Hue — единственная переменная.
